# گزارش تست گزارش‌های مدیریتی

## نتیجه

- بررسی نحوی فایل‌های جدید با `node --check`: موفق.
- مجموعه تست Frontend با `node --test tests/*.test.mjs`: ۳۴ تست موفق، صفر شکست.
- تست Query گزارش‌ها: حذف مقدار خالی، Encoding جست‌وجو، Boolean و تاریخ ISO موفق.
- بررسی Runtime فایل‌های Frontend روی پورت ۸۰۸۰: پاسخ ۲۰۰.
- بررسی OpenAPI بک‌اند فعلی روی پورت ۸۰۰۲: هر ۱۰ Endpoint گزارش در دسترس است.
- تست قراردادهای گزارش بک‌اند با `pytest tests/test_reports.py`: شش تست موفق، صفر شکست (یک هشدار deprecation کتابخانه TestClient).
- پروژه ابزار Bundler یا `package.json` ندارد و به‌صورت ES Modules اجرا می‌شود؛ بنابراین Build جداگانه موضوعیت ندارد و بررسی نحوی/تست/اجرای Static Server جایگزین آن است.

## پوشش دستی پیشنهادی

ورود با کاربر دارای مجوز، Empty/No Access، فیلتر و URL، صفحه‌بندی، چاپ گزارش تک‌صفحه‌ای، RTL موبایل و پاسخ Partial Data در مرورگر بررسی شود.
