# نگاشت مجوز گزارش‌ها

- `reports.read`: ورود به ماژول، خلاصه، پرونده‌ها، اقدامات، رخدادها و گزارش تک‌صفحه‌ای.
- `reports.sla`: تب/بخش SLA.
- `reports.kpi`: تب/بخش KPI.
- Scope پرونده و ردیف‌ها از پاسخ بک‌اند پیروی می‌کند و نام Role در فرانت مبنای تصمیم نیست.
- پاسخ 403 یا state برابر `NO_ACCESS` به‌صورت حالت عدم دسترسی نمایش داده می‌شود و Session حذف نمی‌شود.
