# مشخصات رابط گزارش‌های مدیریتی

- `#/reports`: خلاصه KPI، قیف، Gate و اقدامات فوری.
- `#/reports/pilots`: پیشرفت ۱۹ مرحله‌ای پرونده‌ها با جست‌وجو/فیلتر/مرتب‌سازی سمت سرور.
- `#/reports/actions`: اقدامات مرحله، رخداد، مأموریت و تجاری.
- `#/reports/kpis`: KPIهای کیفیت/تجاری و وضعیت SLA.
- `#/reports/incidents`: رخدادهای مدیریتی و شدت/وضعیت.
- `#/reports/pilots/{id}`: گزارش تک‌صفحه‌ای تصمیم، شواهد خارجی و چاپ.

همه صفحه‌ها RTL، فارسی، Keyboard-accessible و Responsive هستند. فیلترهای مشترک در Hash URL حفظ می‌شوند. ورودی تاریخ با لایه جلالی موجود پروژه نمایش داده و مقدار ISO سازگار با API ارسال می‌کند.
