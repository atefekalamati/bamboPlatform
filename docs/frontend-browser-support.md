# پشتیبانی مرورگر

هدف: دو نسخه پایدار اخیر Chrome، Edge و Firefox؛ Safari 16.4+، iOS Safari 16.4+ و Android Chrome جاری. قابلیت‌های مورد استفاده ES Modules، private class fields، optional chaining، Intl Persian calendar و AbortController هستند. مرورگرهای Legacy و Internet Explorer پشتیبانی نمی‌شوند.

Matrix دستی: عرض‌های 360، 390، 768، 1024 و 1440؛ zoom 200%؛ Keyboard-only؛ RTL؛ Stageهای 6–9؛ جدول‌ها، Modal، DWG و Dashboard.
